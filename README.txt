PULSEBOARD

Aplicación Kanban local para organizar proyectos.

Cómo usar:
1. Descomprimí la carpeta.
2. Abrí index.html en tu navegador, o subí los tres archivos (index.html, style.css y script.js) a un repositorio de GitHub.
3. En GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.

Incluye tarjetas de ejemplo, múltiples tableros, crear/editar/eliminar tareas, arrastrar y soltar, filtros por prioridad/categoría, búsqueda, LocalStorage, tema claro/oscuro y temporizador Pomodoro.

Los datos se guardan solamente en el navegador y dispositivo actual; no hay cuentas ni sincronización entre usuarios. La tipografía web requiere conexión a internet, pero la app funciona sin ella usando fuentes de respaldo.
